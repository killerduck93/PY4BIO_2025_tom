Write a script that for each protein sequence stored in the given human UniProtKB database calculates:

(1) its isoelectric point

(2) its molecular weight

(3) returns all entries satisfying the conditions specified at the command line e.g.: 8.5 <= IEP <=8.7 AND 44000 <= MW <= 45000

Invoking the script without arguments triggers the display of a suggested usage statement:

python related_IEP_MW.py USAGE: python3 related_IEP_MW.py < IEP lower limit (pH) > < IEP upper limit (pH) > < MW lower limit (Da) > < MW upper limit (Da) >
